Срез исследования: 18 сентября 2026 года. Мы сравнили код, контракты памяти
и отдельные тесты. Названия модулей и заявления README не считались доказательством
готовности. Сведения о запуске новой сборки находятся в README и отчётах её проверок.

Также изучены два частных проекта владельца: Mark Second Brain
(`93756953d37e7ad0be7bd156675e3149ec29d889`, снимок с локальными изменениями)

Приватный код, данные, снимки и авторизационные файлы в этот репозиторий не включены;
малые контракты реализованы заново.

## Внешние первичные источники

- [SICA](https://github.com/MaximeRobeyns/self_improving_coding_agent/tree/ed8275dca4d3c5dbf77229964351fe9b424797dc),
  `ed8275dca4d3c5dbf77229964351fe9b424797dc`, MIT, Maxime Robeyns (2025):
  цикл «изменить копию кода — сравнить проверки — сохранить исходники и результаты».
  В Марке это ограниченный эксперимент с отчётом и патчем, без автоматической
  установки. Код и зависимости SICA не копировались; [проверенные детали и ограничения](SICA.md).
- [OpenAI Codex](https://github.com/openai/codex): официальный CLI с входом через
  ChatGPT. В новом runtime он служит провайдером структурированных ответов;
  выполнение прикладных инструментов остаётся у Марка. Профиль рассчитан на CLI
  0.144.1; изменения версии требуют проверки контракта изоляции.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent): ориентир для
  повседневного личного агента, навыков и памяти. Его запущенный сервис не является
  зависимостью Марка; общая база или совместный файл авторизации не требуются.
- [OpenClaw](https://github.com/openclaw/openclaw): ориентир для инструментов,
  устойчивой работы и нескольких агентов. Новый Марк не заявляет совместимость
  со всеми его инструментами и расширениями.
- [Graphiti](https://github.com/getzep/graphiti): референс временного графа знаний.
  Графовый сервер и семантический поиск не входят в обязательную установку.
- [Telegram Bot API](https://core.telegram.org/bots/api): официальный контракт
  polling, идентификаторов обновлений, отправки сообщений и файлов.
- [SQLite](https://www.sqlite.org/docs.html): транзакции, WAL, FTS5 и резервное
  копирование канонического локального состояния.

Это список происхождения идей, а не заявление о включении этих проектов в пакет.
Основное приложение использует стандартную библиотеку Python и отдельный Codex CLI.

## Остальные репозитории аккаунта

Для определения границ прочитаны README `wildberries-content-genius`, `Zavod_v2`,
`board-unity-project` и приватного приложения Board Unity. Это предметные
приложения контента и сообществ, не более зрелое универсальное ядро Марка.
Асинхронные задания, происхождение данных и доставка артефактов — полезные
общие подходы; их бизнес-модули и приватные данные не переносились.
README `servisWB` через connector вернул 404, поэтому полный аудит этого
репозитория не заявляется. Анализ этих дополнительных проектов ограничен
документацией, в отличие от основного code-review доноров памяти выше.

## Что установлено при проверке доноров

Выборочные тесты моделей Mark Second Brain: 5 прошли. Проверка хеша опыта
Graphiti_fractal: 1 прошла. Выборочные тесты Fractal-memory не собрались без
`graphiti_core`; тесты governor на Windows не собрались из-за `fcntl`.
Telegram Sheets изучен по коду. Эти результаты не доказывают готовность доноров
или новой сборки в production и не заменяют её собственные проверки.
