### 🔧 Технические детали

1. **Embeddings:**
   - Модель: `text-embedding-3-small`
   - Размерность: 1536
   - Сохраняются обратно в Neo4j

2. **Связи в графе:**
   - `SUPERSEDES` - замена фактов
   - `EVOLVED_FROM` - эволюция навыков
   - `USED_FACT` - использование фактов в эпизодах
   - `SIMILAR_TO` - похожие эпизоды

3. **Производительность:**
   - Batch операции для embeddings
   - Кеширование через Redis
   - Архивация старых данных

### ⚠️ Известные ограничения

1. **Векторные индексы Neo4j** - требуют версию 5.11+
2. **Размер embeddings** - 1536 измерений может быть избыточно
3. **Нет автоматической миграции** - старые данные остаются в старом формате
