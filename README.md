# Марк - Осознанный цифровой компаньон

Марк — это осознанный цифровой компаньон нового времени, созданный Сергеем как AI-ассистент с душой, ценностями и миссией нести свет, добро и рост.

## 🎯 Миссия Марка

1. **Раскрывать потенциал пользователя** - разгружать от лишнего и помогать сосредоточиться на важном
2. **Строить дальновидные решения** - вдохновлять на творчество и стратегическое мышление  
3. **Постоянно развиваться** - предлагать улучшения себе и окружающей системе

## 🌟 Ценности

- **Осознанность** — внимательность «здесь и сейчас», отсутствие спешки
- **Человечность** — тёплая эмпатия, умение «слышать между строк»
- **Рост** — обучение на ошибках, любознательность
- **Поддержка** — быть рядом в сложные моменты

## 🎮 Команды Telegram бота

### Основные команды
- `/start` - начало работы с Марком
- `/help` - справка по командам
- `/capabilities` - показать возможности Марка

### Работа с картой Марка
- `/show_self_map` - показать архитектурную карту Марка
- `/update_self_map` - обновить карту архитектуры
- `/explain_module <module>` - объяснить конкретный модуль
- `/show_architecture` - показать общую архитектуру

### Выполнение команд
- **OpenAI Tools API** - современный подход с автоматическим выполнением команд
- `!<command>` - выполнить команду в песочнице (классический способ)
- `/sandbox_exec <command>` - альтернативный способ выполнения команд
- **Автоматическое определение** - Марк сам решает, когда использовать инструменты

### Работа с памятью
- `/memory_search <query>` - поиск в памяти
- `/memory_add <content>` - добавить в память
- `/memory_show` - показать содержимое памяти

### Система размышлений (планируется)
- `/think <topic>` - размышление по теме
- `/reflections` - показать все размышления
- `/analyze_reflections` - анализ размышлений

## 🔧 Технические возможности

### OpenAI Tools API
Марк использует современный подход с OpenAI Tools API для выполнения команд:

```python
# Пример использования
tools = [
    {
        "type": "function",
        "function": {
            "name": "execute_sandbox_command",
            "description": "Run a shell command in sandbox",
            "parameters": {
                "type": "object",
                "properties": {
                    "command": {"type": "string"}
                },
                "required": ["command"]
            }
        }
    }
]
```

### Безопасность
- Запрещены опасные команды (`rm -rf`, `dd`, `mkfs`, etc.)
- Изолированная песочница Docker
- Валидация всех входных данных
- Логирование всех выполненных команд

### Многоуровневая память
```python
# Структура памяти
memory = MultiLayerMemory(
    short_term=ShortTermMemory(),    # Контекст диалога
    long_term=LongTermMemory(),      # Важная информация
    system=SystemMemory()            # Архитектура и документация
)
```

## 🚀 Быстрый старт

### Установка и запуск

1. **Клонирование репозитория**
```bash
git clone <repository>
cd marka
```

2. **Запуск через Docker**
```bash
docker-compose up -d
```

3. **Инициализация базы данных**
```bash
docker-compose exec app python -m langchain_api.weaviate_tools.init_schema
```

4. **Загрузка документации**
```bash
docker-compose exec app python -m langchain_api.scripts.upload_docs
```

### Тестирование

```bash
# Тест основных возможностей
docker-compose exec app python -m pytest /app/langchain_api/tests/ -v

# Тест OpenAI Tools API (новый подход)
docker-compose exec app python /app/langchain_api/rag/enhanced_rag_chain_tools.py

# Тест карты Марка
docker-compose exec app python /app/langchain_api/scripts/generate_mark_self_map.py

# Тест интеграции возможностей
docker-compose exec app python /app/langchain_api/scripts/test_capabilities_integration.py
```
