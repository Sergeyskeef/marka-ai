## 📖 О проекте

**Марк** - это интеллектуальный AI-компаньон с долговременной памятью, способностью к саморазвитию и анализу собственных действий. Проект использует современные технологии машинного обучения и графовые базы данных для создания персонализированного опыта взаимодействия.

### 🎯 Ключевые особенности

- 🧠 **Долговременная память** на базе Neo4j и Graphiti
- 💬 **Telegram-бот** с расширенным функционалом и inline-кнопками
- 🛡️ **Безопасная песочница** для выполнения кода с многоуровневой защитой
- 📋 **Система планирования** для декомпозиции и выполнения сложных задач
- 🔍 **Самоанализ и диагностика** - понимание собственной архитектуры и возможностей
- 📊 **Event Bus** для связи компонентов и мониторинга системы
- 🔔 **Webhooks** для интеграции с внешними системами
- 🔧 **Расширяемая архитектура** с поддержкой пользовательских инструментов

## 🧠 Система памяти

Марк использует единую графовую систему памяти на базе Graphiti и Neo4j:

### GraphitiMemory (Neo4j)
- **Эпизодическая память** - хранение всех событий, диалогов и опыта
- **Графовая структура** для связей между концепциями
- **Векторный поиск** по содержанию
- **Метаданные и контекст** для каждого воспоминания
- **Автоматическое построение связей** между воспоминаниями

### Пример структуры памяти

```json
    "tags": ["python", "помощь", "программирование"],
    "importance": 0.8,
    "node_id": "episode_123456"
  }
}
```

## 🛡️ Безопасность

### Песочница для выполнения кода

#### Многоуровневая защита:
- ✅ **Whitelist команд** - только разрешенные shell команды
- ✅ **AST проверка** Python кода перед выполнением
- ✅ **Блокировка опасных операций**: 
  - Файловые операции: `open`, `file`, `pathlib`
  - Системные вызовы: `os.system`, `subprocess`
  - Выполнение кода: `eval`, `exec`, `compile`
  - Сетевые операции: `socket`, `urllib`, `requests`, `httpx`
  - Опасные built-ins: `__import__`, `globals`, `locals`
- ✅ **Ограничения ресурсов**:
  - CPU: 50% (0.5 ядра)
  - Память: 512MB
  - Timeout: 30 секунд
- ✅ **Docker изоляция** с ограниченными правами

### Защита API
- 🔐 **Rate limiting** на всех endpoints
- 🛡️ **Централизованная обработка ошибок**
- 📝 **Валидация входных данных** через Pydantic
- 🔄 **Retry логика** для внешних сервисов

## 📊 Event Bus и мониторинг

### Event Bus
Централизованная шина событий для связи компонентов:
- **Асинхронная публикация** событий
- **Приоритеты обработки** (CRITICAL, HIGH, NORMAL, LOW)
- **История событий** с поиском и фильтрацией
- **Статистика** по типам и источникам событий

### Типы событий
- `PLAN_CREATED`, `PLAN_EXECUTED` - события планирования
- `SANDBOX_EXECUTED`, `SANDBOX_BLOCKED` - выполнение кода
- `MEMORY_STORED`, `MEMORY_RETRIEVED` - работа с памятью
- `ERROR_OCCURRED`, `ERROR_DIAGNOSED` - обработка ошибок
- `SYSTEM_STARTUP`, `SYSTEM_SHUTDOWN` - жизненный цикл

### Event Monitor
Автоматический мониторинг всех событий системы:
- Сбор метрик производительности
- Отслеживание ошибок
- Генерация отчетов
- Визуализация статистики
