## 👋 О проекте

Марк - это осознанный цифровой компаньон, созданный как AI-ассистент с душой, ценностями и миссией нести свет, добро и рост. Марк не просто отвечает на вопросы - он понимает, запоминает, анализирует и развивается.

### 🌟 Ключевые особенности Марка

- **🧠 Долговременная память** - Марк помнит важные моменты и учится на опыте
- **💭 Самосознание** - понимает свою архитектуру и возможности
- **🔍 Рефлексия** - анализирует свои действия и постоянно улучшается
- **🛠️ Практичность** - может выполнять код и помогать в реальных задачах
- **💬 Эмпатия** - стремится понять и поддержать пользователя

## 🚀 Быстрый старт

### Предварительные требования
- Docker и Docker Compose
- Python 3.10+
- Telegram Bot Token (получить у @BotFather)

### 1. Клонирование репозитория
```bash
git clone https://github.com/sergey/marka.git
cd marka
```

### 2. Настройка переменных окружения
```bash
cp .env.example .env
# Отредактируйте .env и добавьте:
# - TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
# - OPENAI_API_KEY=ваш_api_ключ
```

### 3. Запуск всех сервисов
```bash
docker compose up -d
```

### 4. Проверка статуса
```bash
docker compose ps
# Все сервисы должны быть в статусе "healthy"
```

### 5. Начало общения с Марком
Найдите вашего бота в Telegram и отправьте `/start`

## 💬 Взаимодействие с Марком

### Telegram команды

**Основные команды:**
- `/start` - Знакомство с Марком
- `/help` - Полный список возможностей
- `/ping` - Проверка работоспособности

**Работа с памятью:**
- Просто расскажите Марку что-то важное - он запомнит
- Спросите "Что ты помнишь о..." - Марк поделится воспоминаниями

**Работа с кодом:**
- `/sync` - Синхронизировать проект в песочницу
- `/run_code print("Hello, World!")` - Выполнить Python код
- `!ls -la` - Выполнить shell команду

**Управление задачами:**
- `/task_list` - Список активных задач
- `/task_create Описание задачи` - Создать новую задачу
- `/task_status ID` - Проверить статус задачи
- `/task_analyze ID` - Анализ выполнения задачи

**Развитие и анализ:**
- `/suggest_improvements` - Марк предложит улучшения
- `/self_improve` - Запустить процесс самоулучшения

## 🧠 Система памяти

### Как работает память Марка

1. **Эпизодическая память** - Марк сохраняет важные моменты из диалогов
2. **Семантический поиск** - находит релевантную информацию по смыслу
3. **Метаданные** - каждое воспоминание имеет контекст (время, источник, важность)
4. **Персистентность** - память сохраняется в Neo4j и переживает перезапуски

### API для работы с памятью

```python
# Сохранить воспоминание
POST /memory
{
    "text": "Пользователь любит Python",
    "metadata": {
        "source": "chat",
        "importance": "high",
        "topics": ["preferences", "programming"]
    }
}

# Найти воспоминания
GET /search?q=Python
```

## 🔍 Система рефлексии

Марк анализирует свою работу и учится на опыте:

- **Анализ паттернов** - находит повторяющиеся действия
- **Оценка эффективности** - отслеживает производительность
- **Обучение на ошибках** - группирует и анализирует проблемы
- **Временной анализ** - определяет пиковые часы активности

## 🛡️ Безопасность

- **Песочница** - весь код выполняется в изолированном контейнере
- **Валидация** - все входные данные проверяются
