### 3. Новые возможности Graphiti

#### Контроль параллелизма:
```python
self.semaphore_limit = int(os.getenv('GRAPHITI_SEMAPHORE_LIMIT', '20'))
self._semaphore = asyncio.Semaphore(self.semaphore_limit)
```

#### Расширенная схема памяти:
```
User ──[owns]──► Session ──[contains]──► Message
Message ──[triggers]──► Task ──[produces]──► Artifact
Message ──[caused_error]──► Mistake ──[resolved_by]──► Insight
```

#### Менеджер ошибок и инсайтов:
- Запись ошибок с привязкой к контексту
- Автоматическое создание инсайтов
- Анализ паттернов ошибок

### 4. Гибридный поиск (НОВОЕ!)

#### Компоненты:
1. **Векторный поиск** - семантическое сходство
2. **Графовое расширение** - поиск связанных узлов
3. **Временной контекст** - учет актуальности
4. **Персонализация** - учет предпочтений пользователя

#### Использование:
```python
from core.memory.memory_manager import memory_manager

# Гибридный поиск с временным окном
results = await memory_manager.hybrid_search(
    query="найти информацию о последних ошибках",
    user_id="user_123",
    k=10,
    time_window=timedelta(days=7),  # Последняя неделя
    use_hybrid=True
)

# Каждый результат содержит:
# - id: идентификатор
# - text: текст
# - score: комбинированный score
# - source: 'vector', 'graph', или 'hybrid'
# - metadata: дополнительная информация
# - graph_distance: расстояние в графе
# - temporal_relevance: временная релевантность
```
