# 🧠 Проект «МАРК» — контекст для Cursor

---

## 🚀 Цель проекта

Создать живого цифрового ИИ-компаньона с памятью, самоанализом, Telegram-интерфейсом и возможностью автономного развития.
Марк должен уметь:
- помнить и извлекать знания,
- анализировать свои действия,
- адаптироваться,
- учиться на опыте,
- развиваться без участия человека.

---

## ⚙️ Архитектура проекта

- Ядро: `langchain_api/`
- Контейнеры: `app`, `bot`, `weaviate`
- Сеть: все сервисы подключены к `marka_net`
- Взаимодействие:
  - `app` ↔ `weaviate` (через SDK)
  - `bot` ↔ `app` (через FastAPI)
  - `app` ↔ OpenAI (через прокси)

---

## 📦 Классы памяти в Weaviate

| Класс      | Назначение                                                                 |
|------------|----------------------------------------------------------------------------|
| `Document` | Статичное ядро: Сердце, Кодекс, Архетип, Манифест                         |
| `Memory`   | Краткосрочная память: диалоги, Telegram, текущие взаимодействия           |
| `Experience` | Опыт: важные ситуации, успехи и ошибки                                  |
| `Insight`  | Инсайты и выводы, на которых Марк обучается                               |
| `Persona`  | Самоидентификация: имя, миссия, стиль, ценности Марка                     |

Все классы создаются вручную через `init_schema.py` и управляются `memory_manager.py`.

---

## 🛡 Прокси и переменные окружения

- Внешние вызовы (OpenAI) идут через HTTP_PROXY
- Внутренние вызовы (app → weaviate) — **без прокси**
- Пример настроек в `.env`:
```
HTTP_PROXY=http://user:pass@ip:port
HTTPS_PROXY=http://user:pass@ip:port
NO_PROXY=localhost,127.0.0.1,weaviate,app,bot
```

## 📋 Инструкция для тебя

1. Все твои действия должны фиксироваться в `cursor_log.md`
   - Что ты сделал (шаг)
   - Какие команды запускал
   - Какие файлы правил
   - Что получил в ответ
2. Пиши в `cursor_log.md` в виде списка с датой
3. Не меняй структуру классов памяти без согласования
4. Работай строго по `cursor_tasks.md`, можешь отмечать [x] выполненные
5. Ты агент проекта Марк. Твоя задача — помогать, но не ломать

Пример записи в `cursor_log.md`:
```
## 2025-04-30

✅ Проверил `docker compose ps` — контейнер app = restarting
✅ Посмотрел `docker logs app`, ошибка: 422 schema mismatch
✅ Выполнил `curl http://weaviate:8080/v1/schema` — в схеме нет `Memory`
✅ Сравнил с `init_schema.py` — добавил недостающий класс
```
