## 🔧 Ключевые компоненты

### 1. **MarkAgent** (app/agents/mark_agent.py)
- Основной агент на базе OpenAI SDK
- Поддержка всех инструментов
- Асинхронная обработка

### 2. **Advanced Memory** (app/memory/)
- Neo4j для графовой памяти
- Graphiti для совместимости
- Унифицированные ID

### 3. **REAP Learning** (app/learning/)
- Reflect: Анализ опыта
- Extract: Извлечение знаний
- Apply: Применение уроков
- Persist: Сохранение в памяти

### 4. **Telegram Bot** (telegram_bot/)
- Модульная архитектура
- Enhanced chat интеграция
- Rate limiting

## 🚀 Как использовать

### Запуск проекта:
```bash

```

### Запуск бота:
```bash
docker compose up bot
```

### Запуск тестов:
```bash
docker compose exec app python -m pytest tests/ -v
```
