## 🔧 Примененные исправления:

### 1. Исправление импортов в Telegram боте

**Проблема**: Смешанные относительные и абсолютные импорты

**Решение**:
- В `main.py` - использовать абсолютные импорты с префиксом `telegram_bot.`
- Добавить `sys.path` для корректного разрешения путей
- В остальных модулях - использовать относительные импорты

### 2. Обновление Dockerfile

**Было**:
```dockerfile
WORKDIR /bot/langchain_api/telegram_bot
CMD ["python", "main.py"]
```

**Стало**:
```dockerfile
WORKDIR /app/langchain_api
CMD ["python", "-m", "telegram_bot.main"]
```

- ✅ `utils.py` для graphiti_service
- ✅ `__init__.py` файлы для правильной структуры пакетов
