# Graphiti Memory — Настройка и сравнение с текущей реализацией

## 1) Рекомендуемая архитектура Graphiti
- **Хранилище:** Neo4j 5.11+ с включёнными плагинами APOC и (опционально) GDS
- **Модель данных:** би‑темпоральный Knowledge Graph (состояние/версия + время)
- **Индексы и поиск:**
  - Векторные индексы (embeddings) для семантики
  - BM25/FTS — полнотекстовый поиск по узлам `Episode`
  - Обход графа — разрешение конфликтов и связей «факт ↔ эпизод ↔ навык»
- **API слой:** Graphiti как единая точка записи/чтения (без параллельной записи напрямую в Neo4j)
- **Метрики:** `/health`, `/metrics`, экспорт Prometheus; отслеживание RPS/latency/ошибок

## 2) Настройка в Docker Compose (наше состояние)
- Сервисы `graphiti` и `graphiti-neo4j` уже присутствуют
- `graphiti` healthcheck и переменные окружения сконфигурированы
- Neo4j 5.11, APOC включен, базовые memory‑лимиты заданы

Рекомендации:
- Убедиться, что включён HTTP/2 и лимиты пула соединений в клиенте (httpx уже настроен)
- Добавить дашборды Grafana (опционально) и экспортеры Neo4j/Redis

## 3) Сравнение «Как должно быть» vs «Как у нас было»
- **Было:** двойная запись (прямой Neo4j + Graphiti), опциональная синхронизация → риск рассинхронизации
- **Стало:** Graphiti‑only по умолчанию, единый путь сохранения/поиска
- **Поиск:** гибридный поиск реализован минимально (через Graphiti FTS), можно расширить rerank/вектор
- **Модели:** Pydantic‑схемы у Graphiti клиента уже используются частично; можно формализовать доменные типы

## 4) Что удалить/упростить
- Дублирующие ветки сохранения в `AdvancedMemoryAdapter` (сделано)
- Временные флаги `USE_DIRECT_NEO4J`, `SYNC_TO_GRAPHITI` оставить для совместимости, но по умолчанию выключены
- При желании — удалить прямой клиент Neo4j из путей записи, оставить только утилитарные чтения/админ‑операции

## 5) Следующие шаги
- Прогнать e2e/smoke с Graphiti‑only
- Добавить простой rerank (по score/времени) к результатам FTS (опционально — векторная часть)
- Формализовать доменные типы (Pydantic) для фактов/эпизодов/навыков и убедиться в консистентности метаданных
- Подготовить Grafana дашборд (latency, errors, memory/CPU)
